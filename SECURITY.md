# Security policy

## Supported versions

Only the latest release gets fixes.

| Time Capsule | Minecraft | Loaders | Supported |
| --- | --- | --- | --- |
| 1.0.x | 1.20.1, 1.21.1, 26.1.2, 26.2, 26.3 | Fabric, Forge, NeoForge | Yes |

## Report a vulnerability privately

Please don't open a public issue for security problems, so nobody can use them before a fix is out.

1. Open the repository's **Security** tab and choose **[Report a vulnerability](https://github.com/Httpsluch/TimeCapsule/security/advisories/new)**. Only you and the maintainer can see the report.
2. Include the Time Capsule version, Minecraft version and loader, what someone could do with the problem, and steps to reproduce it.

You'll get a reply within 7 days. Fixes ship in a new release, and the changelog credits you unless you'd rather stay anonymous.

## What to report here

- Ways to open a sealed capsule early, take items out of one, or duplicate items with it on a multiplayer server.
- Ways a player can crash or lag a server using a capsule.
- Anything that lets the mod read or write files, or run code, that it shouldn't.

Ordinary bugs and single-player crashes are welcome as normal [issues](https://github.com/Httpsluch/TimeCapsule/issues/new/choose).

## Download safely

Only download Time Capsule from [Modrinth](https://modrinth.com/mod/time-capsule), [CurseForge](https://www.curseforge.com/minecraft/mc-mods/sealed-time-capsule) (as Sealed Time Capsule) or this repository's [Releases](https://github.com/Httpsluch/TimeCapsule/releases). Copies on other sites may be modified or contain malware.
